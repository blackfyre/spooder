# Tasks

## 1. Foundation

- [ ] 1.1 Create `hardware/parametric-reference-parts/` with `build.py` (`--test`, `--check`, default), its inline dependencies pinned as the electronics mount's (build123d 0.13.0, numpy 2.1.3, trimesh 4.5.3, the closest-point query's dependency, `exclude-newer`) and `build.py.lock` (`uv lock --script`); discovery of `<source>/parts/*.py` (not `_*.py`) and their `PARTS` declarations, failing on a duplicate name or STL, on a discovered file declaring no part or more than one (two for a mirrored pair, whose second side has `mirror_of` and no `build`), and, by an `ast` scan before import, on any file in `parts/` (the `_` helpers included) that imports outside the allowlist or calls `open`, `exec`, `eval`, `compile` or `__import__` (design: "Part contract and discovery"). Add the `cad-reference` mise task. Verify `uv run --locked --quiet --script build.py --check` runs on an empty source and reports no parts, and unit tests that discovery finds a part file dropped into a temporary source, ignores `_` files, accepts a `_` helper with no `PARTS`, fails on a duplicate name, on a discovered file with `PARTS = []`, on a file declaring three parts, on a pair whose second side has both `build` and `mirror_of`, and on a part file and a `_` helper that each import `trimesh`, import `pathlib`, call `open`, import `import_stl`, or call `b.import_stl` after `import build123d as b`.
- [ ] 1.2 Implement the gates (design: "Gates"): one valid closed solid, volume, symmetric surface deviation (every vertex of each side's mesh subdivided to 0.5 mm edges plus area samples, each direction reported, maximum over all points and 95th percentile over the area samples), bounding box; per-part exceptions that name a feature and are printed; every failure reported before a non-zero exit with nothing written. Verify unit tests in which each gate fails on a bad synthetic shape (two solids, a missing bore, a face 0.3 mm off, an extra boss, a box 0.2 mm too long, and an extra 1 × 1 × 0.3 mm boss with the area samples' seed chosen so that no area sample lands on it) and passes on the good one, an exception applies to its part only, and a mirrored pair is checked side by side against its own STLs.
- [ ] 1.3 Implement the STEP export (design: "STEP export and re-read"): fixed header timestamp, staging folder, re-read as one solid with matching volume and bounding box, then publish per source by replacing the whole folder (`step/` to `step.old/`, staging to `step/`, rename back on failure, a leftover `step.old/` resolved at start). Verify unit tests that an unchanged part writes a byte-identical file, a removed part's file is gone after publishing, a failed re-read leaves `step/` unchanged, a stubbed failure of the second rename leaves the old `step/` complete, a leftover `step.old/` with no `step/` is restored by the next build in `--check` mode as well, and publishing one source leaves another source's `step/` alone.
- [ ] 1.4 Implement the import checks (design: "Import checks"): `freecad_import.py` under `FreeCADCmd` in the flatpak, and `solidcraft-cli eval`, each reporting `PASS` with the version, `FAIL` with the measured value or `SKIPPED` with the reason, and a summary of skips per tool. Verify a unit test with both tools hidden from `PATH` (and the flatpak lookup stubbed) prints `SKIPPED` for each and exits zero, unit tests with stubbed tool output fail for each mismatch (two solids, an open shell, a volume 0.2 % off) naming the part, the tool and the value, and a local run on a synthetic part passes in FreeCAD 1.1.4 and solidcraft-cli 0.30.1.

## 2. Frame group

- [ ] 2.1 Measure each frame STL's tessellation chord error (design: "Tolerances"): fit circles to the vertex loops of its curved features in trimesh sections, giving r, n and r(1 − cos(π/n)). Record the per-part maximum in design.md's tolerance section, and declare an exception for any part above 0.15 mm. Verify the measurement script prints each part's chord error and its result matches the recorded table.
- [ ] 2.2 Model Frame Bottom and Frame Top in `aecert-hexapod-v1/parts/`, from named dimensions measured with trimesh (sections and probes), one arm modelled and patterned at the gait's mount angles (0°, ±56° from the sides), in the STLs' shared coordinates. Verify `build.py --check` passes both against their STLs, and the Bearing Axle Mount hole pairs lie 87.60 mm (middle) and 98.13 mm (corners) from the centre, 28.5 mm apart, as `hardware/aecert-hexapod-v1/README.md` states.
- [ ] 2.3 Model Servo Mount, Bearing Axle Mount and Hubcap the same way, each in its STL's coordinates. Verify `build.py --check` passes all three; a unit test that discovers the Aecert source asserts the declared names are exactly the five frame parts; a unit test that raises one named constant of Hubcap (its thickness) by 0.5 mm and rebuilds sees the volume or surface gate fail; and the Servo Mount's 15 mm ring and 5 mm ear pads and the Bearing Axle Mount's 9.90 mm axle offset and 9.4 mm base match the README's figures.
- [ ] 2.4 Export the five parts to `aecert-hexapod-v1/step/` and commit them. Verify `mise run cad-reference` passes with every FreeCAD and solidcraft import check reporting `PASS`, and a second run leaves `git status` clean.
