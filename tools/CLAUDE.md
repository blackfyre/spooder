# tools/

- `virtual-robot/`: the virtual robot, a native C++17 program (CMake, Ninja; `mise run virtual-robot`) running `core/robot/robot_tick` behind a pseudo-terminal that acts as the robot's USB port (frames and debug text as on the board), optionally a second one for the bridge link, or a simulated bridge. Simulated supply and servo current; commands on standard input (`supply V`, `current A|auto`, `load K`, `bridge off|idle|gamepad|clear`, `estop on|off`, `unplug`, `plug`, `step N`, `status`, `quit`); `--help` lists the options (`--link`, `--speed`, `--stepped`, `--bridge-pty`). The desktop calibrator connects with `--port build/virtual-robot/usb`; `mise run desktop-sim` runs both.
- `bridge-screenshots/`: renders the bridge screen's pages in chosen states to PNGs with the bridge's own `screen_draw` and `core/status` code on the host (LovyanGFX's Linux back end, no panel); `mise run bridge-screenshots` writes `docs/images/bridge-*.png`.
- `worktree.sh`: delivery worktrees (`mise run worktree-add <name> [base]`, `worktree-remove <name>`): `.claude/worktrees/<name>` on branch `deliver/<name>`, from `origin/main` by default, with the submodules cloned from the primary checkout (which must have run `mise run setup`) and `.pio-core` shared by a symlink.
- `vulncheck.sh` (`mise run vulncheck`): govulncheck (pinned) of `desktop/` against `desktop/vulncheck-baseline.txt`. It fails on a called vulnerability the baseline does not list, and on a listed one no longer found: the baseline only shrinks.
- `risk-tier.sh <base> [head]` (or `-` with paths on standard input): a change's risk tier from the paths it touches (`REVIEW.md`). A new sensitive path belongs in its high list.
