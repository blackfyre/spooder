# Supply bands (openspec change handheld-observations, design D3), written by
# hand: the cases core/status/supply_band and the handheld's Go copy
# (desktop/handheld/internal/supplyband) are both run over.
#
#   limits <brownout mV> <undervoltage mV> <overvoltage mV> <sustained mA> <trip mA>
#   voltage <mV> <band>
#   current <mA> <band>
#
# Bands: unknown (limits out of order), ok, warning, fault. Each reading is
# judged against the limits line before it.

# power_limits.example.h: a 6 V BEC for the MG996R servos. The warning margin
# is undervoltage - brown-out = 400 mV on both sides.

voltage 5200 fault

voltage 5599 warning

voltage 6400 ok
voltage 6401 warning
voltage 6799 warning
voltage 6800 fault
voltage 7840 fault
voltage 65535 fault
current 0 ok

current 5999 ok
current 6000 warning
current 8999 warning
current 9000 fault
current 9500 fault
current 65535 fault
