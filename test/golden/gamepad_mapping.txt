# Spooder gamepad mapping: golden steps.
# Written by hand (add-handheld-controller, design D2), never generated.
# test/test_gamepad_mapping_golden runs core/gamepad_mapping over it, and
# desktop/handheld/internal/padmap its Go port, so the two stay in step.
# A mismatch is fixed in the code, not by editing an expected value to match.
#
# "reset <name>" starts a sequence with a fresh Mapper. Each step line is one
# pad sample and the desired state update() returns for it, fields separated
# by single spaces:
#   <t_ms> <connected> <axisX> <axisY> <axisRX> <axisRY> <buttons> <dpad> <misc>
#     = <mode> <translateX> <translateY> <rotate> <height> <speed> <gait>
#       <stride> <stickMode> <controllerConnected> <clearCounter>
#       <modeRequestCounter> <gesture> <gestureRequestCounter>
# (on one line). Axes are Bluepad32 units (Y negative for up). Buttons are
# '+'-joined names from A B X Y L1 R1 L2 R2 THUMB_L THUMB_R, the D-pad from
# UP DOWN RIGHT LEFT, misc from HOME BACK; '-' is none. Connected is 0 or 1.
# Mode is Stand, Walk, Sleep or Calibrate; stride Dynamic or Fixed; stick
# mode Steer or Crab; gesture the protocol GESTURE_* id.
# Lines starting with # are comments.
